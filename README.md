# PresenceWatch

![Version](https://img.shields.io/badge/version-1.6.1-5865F2?style=flat-square)
![Platform](https://img.shields.io/badge/platform-Android-3DDC84?style=flat-square)
![Client](https://img.shields.io/badge/client-Revenge-5865F2?style=flat-square)

**PresenceWatch** — плагин для Revenge на Android, который отслеживает Discord presence выбранных пользователей и может отправлять системные уведомления при входе в сеть, выходе, смене статуса и других поддерживаемых событиях.

> PresenceWatch работает локально внутри Discord-клиента и видит только те presence-данные, которые Discord реально передаёт текущему аккаунту.

## Текущая версия

**v1.6.1**

URL установки:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

## Требования

- Android;
- Discord с установленным Revenge;
- разрешённые уведомления Discord в Android;
- Discord должен реально получать presence отслеживаемого пользователя.

## Установка

1. Откройте Discord с установленным **Revenge**.
2. Перейдите в настройки Discord.
3. Откройте **Revenge → Plugins**.
4. Нажмите **Add Plugin / Install Plugin / +**.
5. Вставьте:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

6. Установите **PresenceWatch**.
7. Включите плагин в списке Plugins.
8. Полностью перезапустите Discord.
9. В настройках PresenceWatch проверьте, что указано **VERSION 1.6.1** и статус **Активен**.

## Как работает мониторинг

PresenceWatch v1.6.1 использует сразу несколько источников:

- актуальный Discord event `PRESENCE_UPDATES`;
- старый `PRESENCE_UPDATE` как fallback;
- `PresenceStore` polling каждые 3 секунды;
- `PresenceStore.isMobileOnline()`;
- `PresenceStore.isVROnline()`.

Это позволяет продолжать отслеживание даже если один из внутренних event-механизмов Discord временно не срабатывает.

В разделе **Мониторинг и уведомления** отображаются:

- найден ли `PresenceStore`;
- notification backend;
- время последнего `PRESENCE_UPDATES`;
- время последнего старого `PRESENCE_UPDATE`;
- состояние polling;
- число проверок;
- источник последней смены статуса;
- время последнего вызова push;
- `status / raw status / mobile / VR` для отслеживаемых пользователей.

## Проверка системных уведомлений

После установки:

1. Откройте PresenceWatch.
2. Нажмите **Тест уведомления**.
3. Если уведомление не появилось, откройте **Настройки уведомлений Android**.
4. Разрешите уведомления Discord.
5. Убедитесь, что Android не ограничивает Discord слишком жёсткой экономией батареи.

В разделе **Группы** можно создавать собственные группы и распределять отслеживаемых пользователей.

Удаление группы не удаляет пользователей из Watchlist.

## Safe Mode

Safe Mode применяется только к дополнительным UI-модулям.

Ядро:

- presence;
- `PRESENCE_UPDATES`;
- polling;
- activities;
- notifications

не отключается Safe Mode автоматически.

## Ограничения

PresenceWatch не может определить настоящий статус **Invisible** — Discord показывает его как **Offline**.

Плагин не является ботом и не запрашивает статус произвольного Discord ID через отдельный API. Он использует данные, уже доступные текущему Discord-клиенту.

Если Discord не передаёт presence конкретного пользователя вашему аккаунту, PresenceWatch тоже не сможет определить его online-статус.

Если Android полностью остановил процесс Discord, плагин не сможет работать до повторного запуска процесса.

Для более стабильной работы в фоне рекомендуется:

- разрешить Discord работать в фоне;
- отключить жёсткую оптимизацию батареи для Discord;
- разрешить уведомления Discord.

## Если уведомления не приходят

Проверьте:

1. PresenceWatch показывает **Активен**.
2. `PresenceStore` показывает **найден**.
3. Счётчик polling увеличивается.
4. Пользователь есть в Watchlist.
5. У пользователя включено **Вход в сеть**.
6. Mute выключен.
7. Не активны тихие часы.
8. **Тест уведомления** реально показывает системное уведомление.
9. В диагностике смотрите `PRESENCE_UPDATES`, `raw`, `mobile`, `VR` и источник последней смены.

Если polling работает, но пользователь постоянно отображается как `offline`, `mobile=нет`, `VR=нет`, значит Discord сам не отдаёт клиенту online-presence этого пользователя.

## Если плагин не включается

1. Полностью выгрузите Discord.
2. Запустите Discord снова.
3. Проверьте версию PresenceWatch.
4. При необходимости удалите плагин и установите заново:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

5. Проверьте **Журнал ошибок**.

## Важно

Revenge является неофициальной модификацией Discord. PresenceWatch не связан с Discord Inc.

Обновления Discord или Revenge могут менять внутренние модули клиента, поэтому отдельные функции иногда требуют адаптации.
