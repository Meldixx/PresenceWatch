# PresenceWatch

![Version](https://img.shields.io/badge/version-1.5.9-5865F2?style=flat-square)
![Platform](https://img.shields.io/badge/platform-Android-3DDC84?style=flat-square)
![Client](https://img.shields.io/badge/client-Revenge-5865F2?style=flat-square)

**PresenceWatch** — плагин для Revenge на Android, предназначенный для отслеживания Discord presence выбранных пользователей. Плагин может показывать системные уведомления при появлении пользователя в сети, выходе из сети, смене статуса и других поддерживаемых событиях.

> PresenceWatch работает локально внутри Discord-клиента и обрабатывает только те presence-события, которые Discord реально передаёт текущему аккаунту.

## Текущая версия

**v1.5.9**

URL установки:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

## Требования

- Android;
- Discord с установленным Revenge;
- разрешённые уведомления Discord в Android;
- доступ клиента Discord к presence отслеживаемого пользователя.

## Установка

1. Откройте Discord с установленным **Revenge**.
2. Перейдите в настройки Discord.
3. Откройте **Revenge → Plugins**.
4. Нажмите **Add Plugin / Install Plugin / +**.
5. Вставьте URL:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

6. Установите **PresenceWatch**.
7. Включите переключатель плагина в списке Plugins.
8. Полностью перезапустите Discord.
9. Откройте настройки PresenceWatch и проверьте, что отображается **VERSION 1.5.9** и статус **Активен**.

## Первый запуск

После установки рекомендуется сразу проверить системные уведомления:

1. Откройте настройки PresenceWatch.
2. Найдите раздел **Системные уведомления**.
3. Нажмите **Тест уведомления**.
4. Если системное уведомление появилось, notification backend работает корректно.
5. Если уведомление не появилось, нажмите **Настройки Android** и разрешите уведомления для Discord.

PresenceWatch также показывает:

- используемый notification backend;
- время последнего `PRESENCE_UPDATE`;
- время последнего успешного push-уведомления;
- последнюю ошибку notification backend.

## Добавление пользователя

PresenceWatch поддерживает несколько способов добавления пользователя.

### Через список личных сообщений

Зажмите диалог в списке ЛС и нажмите **PresenceWatch**.

Если пользователь уже отслеживается, этот же пункт удалит его из Watchlist.

### Через профиль

Откройте профиль пользователя → нажмите `⋯` → **PresenceWatch**.

### Через Discord ID

Откройте настройки PresenceWatch, вставьте Discord ID в поле **Discord ID** и нажмите **Добавить**.

## Группы

В разделе **Группы** можно создавать собственные группы и назначать в них отслеживаемых пользователей.

Удаление группы не удаляет пользователей из Watchlist — они переводятся в состояние **Без группы**.

## PIN и Privacy Mode

В разделе **Безопасность** можно установить PIN длиной 4–8 цифр и включить **Privacy**.

PIN защищает интерфейс настроек PresenceWatch на текущем устройстве. Он не является отдельным криптографическим хранилищем данных.

PresenceWatch v1.5.9 поддерживает PIN, созданные в предыдущих версиях, и автоматически мигрирует старый формат после успешного ввода.

## Safe Mode

Safe Mode предназначен для защиты плагина от ошибок отдельных модулей после обновлений Discord или Revenge.

Если один из модулей несколько раз подряд вызывает ошибку, PresenceWatch может отключить только этот модуль, не останавливая весь плагин.

В настройках доступен сброс состояния Safe Mode.

## Ограничения

PresenceWatch не может определить скрытый статус **Invisible**. Discord передаёт такой статус как **Offline**.

Плагин не является Discord-ботом и не выполняет отдельные запросы к Discord для получения статуса произвольного ID. Он использует presence, уже доступный текущему Discord-клиенту.

Поэтому PresenceWatch работает только для пользователей, presence которых Discord передаёт вашему аккаунту. Общий сервер не всегда обязателен, но сам presence должен быть доступен клиенту.

Если Android полностью остановил процесс Discord, PresenceWatch не сможет получать новые `PRESENCE_UPDATE` до повторного запуска или пробуждения Discord.

Для более стабильной работы в фоне рекомендуется:

- разрешить Discord работать в фоне;
- отключить жёсткую экономию батареи для Discord;
- разрешить системные уведомления Discord.

## Если уведомления не приходят

Проверьте:

1. PresenceWatch включён и имеет статус **Активен**.
2. Пользователь присутствует в Watchlist.
3. Для пользователя не включён **Mute**.
4. Включено уведомление **Вход** либо выбран подходящий preset.
5. Текущее время не попадает в тихие часы.
6. Discord не был полностью выгружен Android.
7. **Тест уведомления** создаёт системное уведомление.
8. После реального изменения статуса обновляется **Последний PRESENCE_UPDATE**.

Если тестовое уведомление работает, но **Последний PRESENCE_UPDATE** остаётся `нет`, Discord не передаёт presence-событие этому клиенту.

## Если плагин не включается или настройки не открываются

1. Полностью закройте Discord.
2. Запустите приложение снова.
3. Проверьте версию PresenceWatch.
4. Если проблема осталась, удалите PresenceWatch и установите его заново по URL:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

5. При наличии ошибки откройте **Журнал ошибок** и скопируйте лог.

## Обновления

Revenge использует `manifest.json` PresenceWatch для проверки обновлений.

При изменении `hash` новая версия должна подтянуться после перезапуска Discord.

Manifest:

```text
install/manifest.json
```

Основной файл:

```text
install/index7.js
```

## Структура репозитория

```text
PresenceWatch/
├── install/

│   └── index7.js

```

Каталог `install/` является готовым источником плагина для Revenge.

## Важно

Revenge является неофициальной модификацией Discord. PresenceWatch не связан с Discord Inc.

Обновления Discord или Revenge могут изменять внутренние модули клиента. Из-за этого отдельные функции PresenceWatch иногда могут потребовать обновления.
