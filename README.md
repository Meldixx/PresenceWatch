# PresenceWatch

![Version](https://img.shields.io/badge/version-1.5.9-5865F2?style=flat-square)
![Platform](https://img.shields.io/badge/platform-Android-3DDC84?style=flat-square)
![Client](https://img.shields.io/badge/client-Revenge-5865F2?style=flat-square)

**PresenceWatch** — плагин для Revenge на Android, который отслеживает Discord presence выбранных пользователей и показывает системные уведомления, когда они появляются в сети, выходят из сети или меняют статус.

> PresenceWatch работает локально внутри вашего Discord-клиента и видит только те presence-события, которые Discord реально отправляет вашему устройству.

## Актуальная версия

**v1.5.9**

URL для установки:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

## Установка

1. Установите и запустите Discord с **Revenge**.
2. Откройте настройки Discord.
3. Перейдите в раздел **Revenge → Plugins**.
4. Нажмите **Add Plugin / Install Plugin / +** — название кнопки может немного отличаться в зависимости от версии Revenge.
5. Вставьте URL:

   ```text
   https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
   ```

6. Установите **PresenceWatch**.
7. В списке плагинов включите переключатель **PresenceWatch**.
8. Полностью перезапустите Discord, если плагин не появился в меню или не начал работать сразу.
9. Откройте настройки PresenceWatch и убедитесь, что сверху отображается **VERSION 1.5.9**.

## Как добавить человека в отслеживание

Есть три способа.

### Через долгое нажатие на ЛС

Зажмите нужный диалог в списке личных сообщений и нажмите **PresenceWatch**.

Если человек уже отслеживается, этот же пункт удалит его из PresenceWatch.

### Через профиль пользователя

Откройте профиль пользователя → нажмите `⋯` → **PresenceWatch**.

### Через Discord ID

Откройте настройки PresenceWatch, вставьте Discord ID в поле **Discord ID** и нажмите **Добавить**.

## Системные уведомления

PresenceWatch использует встроенный Android-механизм уведомлений Discord.

После установки:

1. Откройте PresenceWatch.
2. В блоке **Системные уведомления** нажмите **Тест уведомления**.
3. Если уведомление появилось — всё настроено правильно.
4. Если уведомления нет, нажмите **Настройки Android** и убедитесь, что уведомления для Discord разрешены.

В диагностике PresenceWatch отображаются:

- используемый notification backend;
- время последнего `PRESENCE_UPDATE`;
- время последнего успешного системного уведомления;
- ошибка notification backend, если она возникла.

## Настройка пользователя

Нажмите **Открыть** на карточке пользователя. Там можно изменить имя, группу, иконку, цвет, закрепление, избранное, notification preset, отдельные типы уведомлений и repeat notification.

Кнопка `⚙` на карточке открывает быстрые действия и управление порядком.

## PIN и Privacy

В блоке **Безопасность** можно установить PIN из 4–8 цифр и включить **Privacy**.

PIN защищает только интерфейс настроек PresenceWatch на текущем устройстве. Это не отдельное криптографическое хранилище данных.

Если PIN был создан в старой версии PresenceWatch, v1.5.9 поддерживает старый формат и автоматически мигрирует его после успешного ввода.

## Важные ограничения

PresenceWatch не может получать скрытый статус пользователя. Если человек использует **Invisible**, Discord показывает его как **Offline**.

PresenceWatch также не является серверным ботом и не делает отдельные запросы к Discord за статусом произвольного ID. Плагин обрабатывает presence, который уже получил ваш Discord-клиент. Поэтому пользователь должен быть видим вашему клиенту — например, как друг или через другой доступный Discord-контекст.

Плагин может работать без общего сервера, если Discord всё равно передаёт presence этого пользователя вашему аккаунту.

Если Android полностью остановил процесс Discord, PresenceWatch не может получать новые `PRESENCE_UPDATE`. Отслеживание продолжится после запуска или пробуждения Discord. Для более стабильной работы в фоне можно разрешить Discord работать в фоне и не ограничивать его батареей средствами Android.

## Если уведомление о входе не приходит

Проверьте следующее:

1. PresenceWatch включён и сверху написано **Активен**.
2. Пользователь действительно добавлен в Watchlist.
3. У пользователя не включён **Mute**.
4. Для него включено уведомление **Вход** или выбран пресет **Только вход / Все изменения / Вход + выход**.
5. Не включены тихие часы на текущее время.
6. Discord не выгружен Android из памяти.
7. В блоке **Системные уведомления** работает кнопка **Тест уведомления**.
8. После реального изменения статуса строка **Последний PRESENCE_UPDATE** должна обновиться.

Если тестовое уведомление работает, но `Последний PRESENCE_UPDATE` остаётся `нет`, проблема не в Android-уведомлениях — Discord не передал presence-событие этому клиенту.

## Если плагин не включается

Полностью закройте Discord и откройте его снова. Если это не помогло, удалите PresenceWatch из списка плагинов и установите заново по актуальному URL:

```text
https://raw.githubusercontent.com/Meldixx/PresenceWatch/main/install/
```

Если после обновления что-то сломалось, откройте **Журнал ошибок** в PresenceWatch и скопируйте лог.

## Обновления

Revenge проверяет `manifest.json` плагина. При изменении hash новая версия должна подтянуться автоматически после перезапуска Discord.

Текущий manifest:

```text
install/manifest.json
```

Основной файл плагина:

```text
install/index7.js
```

```text
PresenceWatch/

```

В `install/` лежит готовый plugin repository, который можно напрямую добавить в Revenge.

## Примечание

Revenge является неофициальной модификацией Discord. PresenceWatch не связан с Discord Inc. и использует API/модули, доступные внутри модифицированного клиента. Обновления Discord или Revenge иногда могут менять внутренние компоненты, из-за чего отдельные функции плагина могут потребовать обновления.
